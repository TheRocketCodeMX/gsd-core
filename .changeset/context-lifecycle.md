New `context` capability — the knowledge lifecycle. GSD's fresh-subagent model gains durable, verifiable project knowledge: a bounded `MASTER-CONTEXT.md` index, quality-stamped phase capsules (`<N>-CONTEXT.md`), append-only layers that supersede (never delete), deterministic anchor verification via `gsd-tools context verify` (a failed anchor is annotated `[STALE]`, never silently trusted), a calm context-pressure flush hook, the re-anchor procedure after any compaction, and append-only elicitation discussion logs. The capability seeds at the strategy → build transition (skippable), injects capsule Locked Decisions / Phase-Scoped Pitfalls / What-Done-Looks-Like into executor and verifier, and adds a planner freshness gate + orchestrator curation layer. Enforcement alignment rides along: verifier strategy-set gates, the grounding unflipped-row fix, researcher ADR/DOMAIN-MODEL grounding, and a structured `deviations:` frontmatter field so phase N's reality is visible to phase N+1. Doctrine: plans are perishable; context is durable — front-load the knowledge, never the plans. Capability ids also de-branded: `rocket-learn` → `learn`, `rocket-strategy` → `strategy`, `rocket-grounding` → `grounding`.
