**Realigned the fork onto upstream v1.10.0 (189 commits), with every fork feature re-placed and guard-verified.** What arrives from upstream: plan-phase stall detection plus chunked planning, so a long plan run reports progress instead of appearing to hang; per-PR emitted-drift ack fragments, which replace the single shared ack file that every concurrent PR collided on; bounded-subprocess test seams (a new `local/no-unbounded-spawn` rule and the timeout plumbing behind it) so no test can spawn a child that outlives the run; new-project section manifests; a sync-skills routing fix that dispatches through the shipped `gsd-tools` instead of an installer entrypoint that never ships; the bracket phase-id grammar, still flag-gated and now carrying a fork consumer warning when `phase_id_convention` selects the grammar nothing consumes yet; and test-lane sharding. The fork's own surfaces — grounding hook and index, source-fidelity, context lifecycle, capability set, marketplace identity — were re-placed on top and verified against the fork-delta guard.

Two install-surface defects the realignment surfaced are fixed here, both upstream-owned and both invisible to the unit lane. `hooks/lib/isolation-sentinel.js` (the helper the agent-isolation guard and the Cursor subagent-start hook both require) shipped to installs through the `hooks/dist` subdirectory recursion but was never added to the installer's managed `hooks/lib/` roster: uninstall left the file behind — and with it a non-empty `hooks/lib/` that could never be pruned — while the install manifest never tracked it, so update's custom-file detection reported it as a user file forever. Separately, the installer-migration ledger recorded a zero-action migration only when the *entire* run was action-free; as soon as any unrelated migration had work, the no-op siblings dropped out of `gsd-install-state.json` and stayed pending indefinitely. A migration is complete once its `plan()` finds nothing to do, so both paths now record it, checksum pinned. Riding along: managed-hook coverage for the realistic-install matrix, and an explicit `HEAD` revision on the cicd-strategy contributor shortlog so it no longer fails in a detached or freshly-cloned checkout.
